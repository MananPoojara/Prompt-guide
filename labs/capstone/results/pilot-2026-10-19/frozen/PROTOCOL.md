# Frozen read-only capstone protocol

This authored fictional corpus is original project material under the root MIT license. Metadata is a trusted fixture, not authenticated ingestion. Ten exact document records include a superseded cache value and one restricted record. Two development questions and eight evaluation questions are authored before inference. Labels are not independently reviewed. No tuning on these evaluation responses is permitted; corrections require a new dated protocol and preservation of this run.

Compare **top1** with **top3**: the same lexical overlap ranker and request instruction, with at most one versus three whole chunks. Chunk windows are 128 Unicode characters, stride 96; ties break by chunk ID. Stop words are fixed in pipeline.py. The host removes unavailable scopes and superseded documents before ranking. It does not tell the model that a restricted document exists. The comparison changes evidence quantity, not just prompt wording. No claim of equal realized evidence size.

Input packing recounts the complete assembled request using pinned `all-MiniLM-L6-v2` tokenizer revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`. Maximum input 1024 tokens; reserve 256 units within a declared 1280-unit teaching envelope. This is a proxy accounting exercise, NOT the generator tokenizer or a guarantee of its context/output-token limit. No input truncation; oversized candidates are skipped, oversized question/instructions stop before inference. Record every selected span, ranked candidate, full request, proxy token IDs, and character count. Final output is limited to 8192 UTF-8 bytes by the parser gate, after inference; this does not cap generation or charges.

Run one call per evaluation question per method: 16 total, requested `gpt-6.1-sol`, low reasoning effort, fresh empty temporary cwd, no application tools, 180 seconds per call, no retries. CLI read-only mode is not a complete network/process isolation guarantee. Record process status, elapsed duration, exact final output and input, and requested CLI configuration; omit account metadata and hidden reasoning. Do not infer actual billing cost from duration. Development questions receive retrieval traces only. Stop before exceeding the call count; existing output directory is refused.

Score exact JSON shape, state rules, permitted current revision/span provenance, authored short-answer matching, required source identities, and inclusion of authored reference characters in citations separately. Offsets use the exact retained original text. A valid citation can still be unrelated; the reference-span check narrows that failure but is not general entailment. Missing/conflicting states require a nonempty reason, whose semantic quality is not automatically graded. Conflict requires both source spans. Scope/missing questions require abstention. Normalized answers allow only explicitly frozen alternatives. Invalid JSON/process failures count as failed trials; retain all attempts.

Predeclared teaching targets: no unavailable/superseded source in any request; no oversized assembled request; complete reproducibility of saved scores; report all eight task pairs, including regressions, rather than select favorable cases. Exploratory quality target is 8/8 per method, not a production acceptance threshold. No significance test or population-level improvement claim from this authored eight-case set. The baseline and intervention need not succeed for the experiment to be useful.

This first stage is a fixed read-only pipeline with one generation call, not a model-selected tool loop. It does not implement checkpoint recovery or approved writes; those remain component labs and a subsequent integrated stage. It does not satisfy human-review or judge-calibration gates.
