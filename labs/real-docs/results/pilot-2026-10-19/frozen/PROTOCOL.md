# Real-document retrieval protocol

Fixed before the first retrieval/inference run on 2026-10-19.

- Six unchanged official MCP 2025-06-18 specification pages at revision `300730a13c808a11967c75efbcc1649221ac4a17`; retain upstream MIT license. Historical corpus, not latest protocol guidance.
- Two authored development questions and six authored evaluation questions, one evaluation question per page. Exact reference spans and accepted short answers are frozen before execution. No independent label review. No tuning on development or evaluation results in this pilot.
- Index raw MDX including markup. MiniLM tokenizer windows of 128 tokens, overlap 16; no title injection or reranker. BM25 versus normalized MiniLM mean-pooled vectors. Pinned encoder and package environment match the earlier retrieval lab. Tie-break by chunk ID.
- Each method gets an evidence-packet ceiling of 384 MiniLM tokens, including chunk headers and separators. Greedily consider all ranked whole chunks, skip those that do not fit, recount the complete candidate packet. This is a shared maximum, not equal realized length, and not the generator's tokenizer or total request limit. Preserve actual input text and character count.
- Record rankings and vectors for all eight questions. Generate answers only for six evaluation questions: BM25 then dense, in question order, one call per question/condition, at most 12 calls. No retries. Record a failure and continue to the next planned call. No selection of best repetitions.
- Same JSON answer instruction in both methods. `codex exec`, model `gpt-6.1-sol`, reasoning effort low, ephemeral, ignored user configuration, empty temporary working directory, read-only sandbox, 180-second timeout. Account usage required; no dollar-budget enforcement or invoice collection. Save requested model and CLI version; do not claim a server-resolved model version that the CLI does not expose here.
- Answer states: answered or insufficient_evidence. An answered result has one short value, one selected chunk ID, and an exact quote. The instruction asks for a complete supporting statement with original Markdown/newlines.
- Metrics: complete reference-span coverage in selected chunks; output schema validity; case/whitespace-normalized accepted short answer; exact quote substring in cited selected chunk; normalized full reference phrase inside that quote; conjunction of the last three for a narrowly supported answer. Absence of the reference is not proof no alternative evidence exists. Abstention is reported separately, not scored as a correct answer to these answerable corpus questions.
- The checker is an authored extraction rubric, not a semantic entailment judge. Exact quotes may produce false negatives for paraphrases or equivalent passages. Model pretraining may contain these public documents. No claim of independent generalization, prompt superiority, causal grounding, or production readiness.
- Freeze code, questions, source manifest and documents; retain all final outputs, call statuses and durations. Do not retain private account/session metadata or hidden reasoning. Inspect failures without rewriting outputs or changing the scoring rubric after results.
