Cosine compares vector directions: 1 means the same direction, 0 means perpendicular, −1 means opposite. It is not a confidence score or proof of understanding.

02 / Inspect an attention head

Each row is a query position. Columns are key positions it can attend to. Future positions have zero weight in this causal model. Numbers are attention weights, not probabilities that words are true.

Recorded attention weights; each row sums to approximately one

Heads vary. A bright cell describes one mixing operation; residual paths, other heads, and feed-forward blocks also affect the result. This is not a map of the model's complete reasoning.
