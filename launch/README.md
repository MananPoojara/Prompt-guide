# Launch preparation

The public promise is an inspectable resource: original public prompts, the systems around them, and recorded outcomes. Avoid “secret prompts,” “prompt like an insider,” “guaranteed better results,” or “all prompts tested.” Those claims are not established.

## One-day editorial and validation schedule

This is a proposed workday allocation, not a claim that a full day of work has already occurred or a scheduled background job.

| Work block | Deliverable | Release condition |
|---|---|---|
| Source audit | Publisher-owned sources, pinned revisions, licensing decisions | Every copied artifact has attribution and reuse terms |
| Case construction | Original prompts plus inputs, context, tools, and diagrams | Every result is labeled reported or locally executed |
| Reproduction | Retained runs and independently checked artifacts | Failures, ties, confounds, and limits are visible |
| Reader pass | Start page and cases understandable without the chat | A reader can find the prompt and its evidence directly |
| Launch edit | Short X post/thread and useful visual | Claims match the current repository |
