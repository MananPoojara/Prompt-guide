# Retrieval now continues through generated answers on real documents

The [new lab](../labs/real-docs/README.md) preserves six official MCP specification pages and their MIT license at a historical revision. It compares BM25 and MiniLM using the same 384-token evidence ceiling, then records twelve answer calls with the same answer contract.

BM25 covered the complete reference for 5/6 evaluation questions; dense retrieval covered 4/6. Both produced 5/6 correct short answers. The stricter correct-value-plus-complete-quote measure passed 4/6 and 3/6 respectively. Each method abstained once, on different questions. [Every outcome and failure is retained](../labs/real-docs/RESULTS.md).

Readers can now inspect the selected context, generated value, exact quote, and scoring rule together. In particular, a correct answer can fail a strict quotation requirement; that is not automatically a factual error. The six authored questions remain a small unreviewed pilot, and the historical specification is not current implementation guidance.

The offline checker and cached-tokenizer replay passed. Repository CI includes the new unit tests and artifact verifier. The main README remains a short navigation path.
