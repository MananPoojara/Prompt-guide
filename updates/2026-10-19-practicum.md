# Advanced labs now have a guided practice path

The [practicum](../labs/PRACTICUM.md) turns existing runnable labs into seven investigations with predictions, concrete deliverables, and extensions. The [capstone specification](../labs/CAPSTONE.md) connects retrieval, context packing, answer validation, host boundaries, and evaluation into one local developer-assistant project.

The component recordings remain unchanged. The capstone is a project specification, not a recorded integrated implementation or a performance claim. New experiments must preserve the baseline and retain their own evidence.

The local-link checker now resolves one frozen plugin README against its original repository location. This fixes a hosted CI failure without modifying the hashed historical snapshot or skipping its links. All 17 offline evidence checks passed after the correction.
