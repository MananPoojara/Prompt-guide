# Examples and extra steps now have a controlled comparison

The [example-design lab](../labs/example-design/README.md) compares no examples, simple examples, boundary-case examples, those same boundary examples reversed, and an evidence-ledger-then-answer pipeline. Ten authored notes test commitments, replacements, withdrawals, conflicts, relative dates, and quoted instructions.

The [results](../labs/example-design/RESULTS.md) retain every repetition and intermediate ledger. Selection changes example content and length; reversing the same examples changes only their order; decomposition changes the complete execution pipeline. The guide explains those distinctions rather than attributing every difference to prompt wording.

The final-answer checker and input reconstruction run offline. Intermediate ledgers are preserved, not silently repaired or assumed correct. Independent human review and broader tasks remain open.
