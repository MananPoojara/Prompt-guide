## Measured finding: the comparison tied

The [controlled extraction pilot](../labs/prompt-comparison/README.md) compares a short instruction, explicit rules, and the same rules with four examples. Each variant received the same 16 held-out notes in three fresh calls. Every response matched all 16 records.

The useful finding is limited: the added rules and examples produced no observed accuracy advantage on these notes. This dataset did not distinguish the variants. The cases are synthetic and were authored and audited by the experiment designer, not independently annotated. The 48 observations per arm come from three batched calls, not 48 independent trials.

The [result report](../labs/prompt-comparison/RESULTS.md) links all inputs, outputs, the failed setup attempt, frozen protocol, and offline checks. It identifies the runtime and explains why its duration observations do not establish a reliable speed ranking.

## What readers can do

Start with the first worked example, then inspect a saved response and its check. If you already build with agents, run the local MCP demonstration or re-score the controlled pilot. Choose an external integration only when it serves a concrete task.
