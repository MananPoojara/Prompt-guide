# Curate durable memory

**Use:** After a verified decision or finding.

## Copy and adapt

```text
Create focused memory records from [evidence]. Each record needs an ID, claim, scope, source, review date, and status. Separate user preferences from empirical findings. Exclude credentials and unsupported guesses. Identify records superseded by new evidence. If saving remotely, verify the write and retrieval before saying it is stored.
```

## Check the result

Retrieved records retain provenance and current status.

## Watch for

A summary silently upgrading an inference to a fact.

Start with the shortest version that communicates the task. Add examples when ambiguity affects the result.
