# Resume interrupted work

**Use:** At the beginning of a new session.

## Copy and adapt

```text
Read [handoff] and the current repository instructions. Verify the worktree, saved artifacts, and any claimed running process. Identify which acceptance criteria are complete with evidence. Continue the next incomplete step without redoing verified work. If the handoff conflicts with current state, explain the conflict and use current evidence.
```

## Check the result

The resumed action matches the real state.

## Watch for

Repeating a stale plan or restarting a live job.

Start with the shortest version that communicates the task. Add examples when ambiguity affects the result.
