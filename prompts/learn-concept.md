# Learn through a concrete example

**Use:** For an unfamiliar AI engineering concept.

## Copy and adapt

```text
Teach me [concept] using one small worked example relevant to [my task]. Define unfamiliar terms when introduced. Show inputs, operations, and observable outputs. Distinguish a conceptual illustration from an executed result. Give me an exercise, success criteria, and the most common misconception. Cite primary sources for technical claims.
```

## Check the result

You can explain and apply the example without copying it blindly.

## Watch for

A metaphor that obscures the actual mechanism.

Start with the shortest version that communicates the task. Add examples when ambiguity affects the result.
