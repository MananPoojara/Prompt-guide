# Understand a repository

**Use:** Before changing unfamiliar code.

## Copy and adapt

```text
Explain how [user action] flows through this repository. Read its instructions and relevant implementation and tests. Identify entry points, module responsibilities, and persisted state with file references. Separate verified behavior from inference. List the commands that would check your explanation. Do not edit files.
```

## Check the result

Follow the cited entry point and one end-to-end path yourself.

## Watch for

A plausible architecture description with nonexistent paths.

Start with the shortest version that communicates the task. Add examples when ambiguity affects the result.
