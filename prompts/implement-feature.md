# Implement a feature

**Use:** After behavior is agreed.

## Copy and adapt

```text
Implement [behavior] in this repository. Read the relevant instructions, implementation, and tests first. Preserve [interfaces and behavior]. Acceptance examples: [examples]. Follow existing conventions. Run checks that cover the change and relevant regressions. Report changed files, commands actually run, results, and unresolved limitations.
```

## Check the result

Inspect the diff and reproduce the acceptance examples.

## Watch for

Tests that pass because they were weakened.

Start with the shortest version that communicates the task. Add examples when ambiguity affects the result.
