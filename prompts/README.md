# Prompt library

Original, adaptable templates. Replace bracketed fields with real information. These are not internal OpenAI or Anthropic prompts. Example outcomes are not measured results unless linked to a recorded experiment.

| Prompt | Use it when |
|---|---|
| [Understand a repository](understand-repo.md) | Before changing unfamiliar code. |
| [Specify a feature](specify-feature.md) | When an idea has unresolved product behavior. |
| [Implement a feature](implement-feature.md) | After behavior is agreed. |
| [Debug with evidence](debug.md) | For a reproducible failure. |
| [Review a change](review.md) | For a diff with known requirements. |
| [Research a claim](research.md) | For a new technique or product claim. |
| [Design a prompt evaluation](design-eval.md) | Before comparing prompt variants. |
| [Critique against a rubric](critique.md) | For a draft with explicit criteria. |
| [Resume interrupted work](resume.md) | At the beginning of a new session. |
| [Design a tool contract](tool-contract.md) | When exposing a capability to an agent. |
| [Curate durable memory](curate-memory.md) | After a verified decision or finding. |
| [Learn through a concrete example](learn-concept.md) | For an unfamiliar AI engineering concept. |
