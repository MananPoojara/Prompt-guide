# Specify a feature

**Use:** When an idea has unresolved product behavior.

## Copy and adapt

```text
Turn this idea into an implementation contract: [idea]. Inspect existing conventions. Define the user-visible behavior, scope, constraints, and acceptance examples including relevant failure states. Identify decisions that materially change the design. Ask only those questions, and state reasonable assumptions for routine choices. Deliver a short specification before implementation.
```

## Check the result

Each acceptance example has a triggering input and observable result.

## Watch for

A large plan that never decides what success means.

Start with the shortest version that communicates the task. Add examples when ambiguity affects the result.
